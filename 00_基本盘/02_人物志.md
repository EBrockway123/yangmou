# 《阳谋》人物志(修订版 v2)

> 所有人物按"三重身份"构建:
> 1. **表面身份** — 朝堂/江湖上的位置
> 2. **真实动机** — 驱使他/她做选择的核心诉求
> 3. **弧光** — 从开篇到结尾,他/她发生了什么变化
>
> 主角之外的角色,**必须有主角视角看不出的暗面**。否则就是工具人。
>
> 修订版改动:
> - 沈彦:补"破落皇族"身世、"不轻易对弈"细化、母亲死的愧疚具体化
> - 苏蘅:感情线改为"知己式寄托";父亲苏崖之死补完;听雨楼渗透真相
> - 萧璎:补"母妃是燕国公主"伏笔的展开
> - 叶孤鸿:渗透设定改为"知道但选择不揭穿"
> - 沈母:死因双层真相(给食物+被灭口)
> - 苏崖:从"10 年前"改为"**6 年前**"(因苏蘅 22-16=6,数字严格对得上),并补完遗物(听雨楼密档)

## 一、沈彦(主角)

| 维度 | 内容 |
|------|------|
| 年龄 | 26 岁(开篇) |
| 出身 | **江南破落皇族后裔**(沈氏旁支,承平十年被清洗除籍);父沈鹤年,原江南盐铁转运副使,**承和元年**"江南盐案"主犯(构陷),死于流放途中 |
| 表面身份 | 新科二甲进士,翰林院编修 |
| 真实处境 | **姓"沈"但不是皇族**——在宗正府已除名。父案被构陷,真凶至今未明。沈彦知道自己是"破落皇族",但**这个秘密绝大多数朝臣不知道**——只有极少数人知道(裴正则、崔玄礼后期猜到) |
| 性格 | 极度自律、克制、隐忍、聪明、内心有炽热但从不外露 |
| 武功 | 不会武功(有自保的短刃功夫,远非高手) |
| 嗜好 | 茶(尤其雨前龙井)、下棋(善弈,**不轻易与人对弈**——只跟"看得懂"的人下)、抄经(静心) |
| 弱点 | 对母亲之死有未愈的愧疚(具体见下);太相信"理"而忽视"情";不敢爱 |
| 死亡 | 不会死。归隐后,在登州开小书院,不知所踪 |

### 三重身份
- **表面身份**:翰林编修,天子的"清贵近臣",前途无量
- **真实动机**:为父翻案,洗清沈家二十一年的冤屈
- **核心追问**(贯穿全书):**"用阳谋为父翻案,本身就是父亲希望我做的事吗?"** ——答案在结尾揭晓:父亲最后留信说"愿吾儿一生清白,不必为我复仇"——但他没看到,等他看到时已经太晚

### 母亲之死的"愧疚"(具体化)

沈彦 5 岁时,沈母(韩氏)在岭南流放地染病。临终前:
- 沈母把仅剩的食物和水都给沈彦和老仆沈安
- 沈彦活下来,母亲死了

**沈彦的"愧疚"**:
- 他觉得自己的命是"母亲换来的"
- **每次端起茶杯、每次夹菜,他都会有一瞬间的停顿**——这是贯穿全书的"小动作"
- 第三幕真相揭开:母亲**不是单纯病死**,是被"灭口"——因为李太后担心沈鹤年死前把证据告诉了妻子
- 母亲**为沈彦多扛了一刀**
- 觉醒:他选"清白地活",**也包括"为母亲而活"**

### 弧光(从起承转合)
- **起**:我相信阳谋,因为阳谋是"正"。我要堂堂正正地为父翻案。
- **承**:我越来越会用阳谋,也越来越"成功"。但我开始感觉到——每次赢,都有些东西消失了。
- **转**:我发现自己的"恩师"才是当年真凶之一。我用的阳谋,正是他希望我用的。我是他的棋子,不是他的门生。
- **合**:父亲临终信到——"不必为我复仇"。我才明白:父亲不是要我"赢",是要我"清白地活着"。我选清白,不要赢。归隐。

### "不轻易对弈"的细化
- 沈彦善弈,但**不轻易与人对弈**——他觉得"下棋是看穿对方,也是暴露自己"
- **唯一的例外:崔玄礼**——因为崔玄礼"看得懂",而且崔玄礼下棋时"不藏"
- 沈彦跟崔玄礼对弈,只发生两次(第二幕扬州瘦西湖别院 + 第四幕登州归隐前)
- 归隐后在登州教孩子,只教"棋理",从不跟孩子对弈——"我可以教你,但我不跟你下"

### 关键台词(用于定调)
- 开篇独白:"我自小被教的是,要做一个'正'的人。可'正'是什么?是把对手按在明处打,还是让自己活在光下?"
- 觉醒时:"我以为阳谋是我的剑。原来阳谋是他们的笼。我不是执剑人,我是笼中鸟。"
- 归隐前最后一句:"这一局,我认输。"

## 二、崔玄礼(亦敌亦友的核心对手)

| 维度 | 内容 |
|------|------|
| 年龄 | 29 岁(开篇,19 岁中进士) |
| 出身 | 清河崔氏,嫡长子,父亲早亡,19 岁中进士 |
| 表面身份 | 翰林学士(正三品),崔氏家主,世家中兴之代表 |
| 真实处境 | 表面风华绝代,实际背负崔氏三百口的存亡。推恩令之下,崔氏的"不罪先朝"丹书铁券,是他们最后的护身符 |
| 性格 | 骄傲、才华横溢、宁折不弯、有贵族气、有时近乎残忍(对自己更残忍) |
| 武功 | 君子六艺皆通,骑射尤精 |
| 嗜好 | 琴(古琴)、棋(国手级别)、品鉴书画、收藏名砚 |
| 弱点 | 把"崔氏存续"看得比自己还重;不会爱(曾爱过一个人,被家族牺牲掉了) |
| 后期觉醒 | 第二幕后期,他**隐约猜到**沈彦是"破落皇族"——但他没有揭穿,也没有利用 |

### 三重身份
- **表面身份**:大衍最年轻的翰林学士,士林领袖,新帝党的"友军"——但实际上他从不站队
- **真实动机**:**让崔氏在推恩令下活下来,且活得体面。** 不图谋反,不图称臣,只图"不被吃干抹净"
- **暗面**:他敬佩沈彦。他看沈彦,像看年轻时的自己——可他早已放弃了自己

### 弧光
- **起**:沈彦是我最大的威胁,但也是最有趣的对手。
- **承**:我开始用"教他"的方式应对他——不,不是教,是"同台对弈"。这让我想起自己当年的样子。
- **转**:我发现沈彦的恩师(裴先生)才是当年盐案的真正推手之一——而我崔氏,只是被借力的刀。我恨。
- **合**:沈彦归隐前,我们最后一次对弈。他认输。我没赢。我替他收拾了残局,因为"这世上,总要有人记得阳谋的样子"。

### 与主角的关系
- **不是"反派",是"镜像"**。崔玄礼是"用了阳谋却输了的人"(因为推恩令之下,世家的阳谋对皇权无效)。沈彦是"还在用阳谋的人"。两人互为"如果继续这样,会变成对方"的隐喻。
- **核心张力**:崔玄礼看沈彦,既欣赏又嫉妒(因为沈彦还有"退出的可能",他没有)。这层关系不写明,但要通过细节漏出来。
- **对弈**:全书只跟沈彦对弈两次(第二幕扬州瘦西湖别院、第四幕登州)——他珍惜"不轻易下"的对手

### 关键台词
- 第一次正面交锋:"沈编修的阳谋,崔某半生读书,自愧不如。只是,阳谋用得再漂亮,也救不了该救的人。"
- 觉醒时对沈彦说:"你以为你比我自由?你不过还没到我这一步。"
- 结局(沈彦归隐前):"沈彦,你知道我为什么从不让你赢吗?因为让你赢,就是让你走到我这一步。我宁可输给一个比我更年轻的人,也不要看到一个比我更年轻的人,变成我。"

## 三、裴正则(终局者,恩师/真凶)

| 维度 | 内容 |
|------|------|
| 年龄 | 73 岁(开篇,承和元年案发时 52,中进士时 19) |
| 出身 | 寒门,五十四年前中进士,仕途跌宕,曾被贬岭南,后起复 |
| 表面身份 | 吏部尚书(正二品),新帝党核心,士林领袖,沈彦的"恩师" |
| 真实身份 | **承和元年**"江南盐案"的真正推手之一——他当年任御史中丞,主导构陷沈鹤年,目的是借沈家人头一石三鸟:灭江南转运副使(掌握铁器走私证据),给崔氏下套,推仁宗上位。**他知道沈彦是"破落皇族"——这是他收沈彦为门生的远因之一** |
| 性格 | 慈眉善目(表面)、深沉如渊(内里)、极度自律、极度自洽——他真心相信自己做的一切是对的 |
| 武功 | 不会武功 |
| 嗜好 | 看人(识人是他最大的爱好)、品茶(雨前龙井)、下棋(国手,经常故意输) |
| 弱点 | 把天下当棋盘,惟独把棋子不当人;他真心欣赏沈彦,但**欣赏不妨碍他用沈彦** |

### 三重身份
- **表面身份**:天子近臣,吏部天官,清流领袖
- **真实动机**:**"再造"大衍**。他不是要当皇帝,他要当"立规矩的人"。推恩令、科举制、阳谋学——这套体系是他二十年来一手推行的。他要的是"天下英才皆入我彀中"。
- **暗面**:他对沈彦有真感情,但他的"真感情"是"我把最好的东西都给你,你也要成为我体系的一部分"。这跟"父爱"很像,但本质上是"系统维护"。

### 弧光
- **起**:我收沈彦为徒,因为我看到他像年轻时的自己。我要教他成为最好的"阳谋家"。
- **承**:他越来越强,我也越来越满意。这证明我的体系是对的。
- **转**:他开始"看穿"一些事。我必须收网了——但我舍不得。
- **合**:他归隐。我没有追他。我坐在空荡荡的书房里,第一次觉得——这棋盘有点冷。

### 与主角的关系
- **是"父"的镜像,也是"父"的延续**。沈彦从未有过的"父爱",在裴正则这里得到了——但这份"父爱"是要付出"做棋子"的代价的。
- **真正的反转**:**沈彦一直以为"裴先生是父亲的朋友,所以才收留我"。** 真相是:裴正则是当年构陷沈鹤年的真凶之一。沈彦"考上进士、投到裴先生门下",是裴正则一手安排的——为了让沈彦"为父复仇"的执念,成为自己可以利用的棋子。
- **座师钩子**:沈彦最初拜的座师,不是裴正则,而是翰林院老学士王公。裴正则用"明升暗降"把王公挤走(调去修书),自己"主动"要收沈彦。这一切**从头到尾是裴正则的设计**。

### 关键台词
- 收沈彦为徒时:"老夫阅人无数,唯见你,像年轻时的自己。"
- 真相揭开时:"你以为你用阳谋为父翻案?你用阳谋为我所用。"
- 沈彦归隐后(自言):"他走了。也好。这棋盘上,少了一个会让我手软的人。"

## 四、苏蘅(知己式寄托,非言情)

| 维度 | 内容 |
|------|------|
| 年龄 | 22 岁(开篇,**6 年前**丧父时 16 岁) |
| 出身 | 听雨楼上一任楼主苏崖的独生女,母亲不详(江湖传言早亡) |
| 表面身份 | 听雨楼少楼主,执掌天下第一情报网 |
| 真实处境 | 听雨楼表面中立,实则**已被多方渗透**。她父亲苏崖**六年前被暗杀**——苏蘅接位后,一边维持中立,一边暗中查凶手。她**知道听雨楼有渗透**,但选择先稳住大局再查 |
| 性格 | 冷厉、聪明、有野心但不外露、内心有一块柔软(对"真"的人) |
| 武功 | 高(听雨楼有数位高手护卫) |
| 嗜好 | 听雨(字面意思)、读志怪、看人说话时的微表情 |
| 弱点 | 父亲之死的真相有执念;**对"另一种活法"有过度的羡慕** |

### 三重身份
- **表面身份**:听雨楼少楼主,大衍情报市场的"女王"
- **真实动机**:**找出杀父真凶,并保证听雨楼"不站队"地活下去**。她比任何人都明白"站队"是死路一条
- **暗面**:她**把沈彦当成"另一种活法"的寄托**——她不能选归隐(她要留在听雨楼),所以她把"归隐的可能"寄托在沈彦身上。**这不是言情式"喜欢",是知己式"我懂你"**

### 父亲之死(苏崖,六年前)

- **苏崖(听雨楼前楼主)**:30 年前创立听雨楼,把听雨楼做成"天下第一情报网"。为人刚正,坚持"不站队"
- **六年前(承和十六年)被暗杀**——凶手不明,听雨楼内部一度混乱
- **苏崖遗物**:留有一份"听雨楼最危险的档案",锁在只有下一代楼主能打开的密室里
- **档案内容**:**江南盐案部分原始材料 + 一份手抄的李太后批复(非亲笔,是苏崖当年从宫里抄出来的副本)**
- **这份档案**是第三幕翻案的关键证据——但因为是"手抄"不是"亲笔",不能作为"铁证",只能作为"线索"
- 苏蘅给沈彦,是因为"这份档案跟我父亲的死有关,我希望有人能查清"

### 弧光
- **起**:沈彦是我最有趣的"客户",也是最危险的变量。
- **承**:我开始主动给他情报,不是因为钱,是因为——我想看他怎么赢。
- **转**:我发现沈彦的恩师(裴正则)跟我父亲的死有关。我必须告诉他。这会毁了他。但我还是告诉了。
- **合**:我告诉他了。他归隐前,我们最后一面,什么都没说。但我知道——他懂了。

### 与主角的关系
- **不是"爱人",是"知音"**。两人之间的感情,是"彼此看得懂、又彼此留有余地"的微妙
- **她的感情是"看见":她想看他"能走到哪一步"**——他敢归隐,她不敢,所以她愿意**成全**他的归隐
- **不写明爱情,写"我懂你,所以我不留你"**——这是最有力量的轻感情

### 关键台词
- 第一次见面:"沈编修,你的脸告诉我,你要算计人。你的眼睛告诉我,你还在怕。"
- 中期给情报时:"这次不收钱。下次加倍。"
- 给档案时:"我不知道这是什么。但它跟我父亲的死有关。你帮我查清,我帮你查清。"
- 沈彦归隐前夜,她隔着听雨楼的雨幕,看着他离开的方向,自言:"你自由了。"

## 五、萧璎(晋阳王世子·第四变量)

| 维度 | 内容 |
|------|------|
| 年龄 | 28 岁(开篇) |
| 出身 | 晋阳王嫡长子,**母妃是燕国公主(二十年前政治联姻,已故)** |
| 表面身份 | 藩王世子,北疆十万边军的未来统帅 |
| 真实处境 | 憨厚外表下,是另一头狼。他从小被母亲(燕国公主)教导"晋阳萧氏不能亡"。推恩令下,他比任何人都焦虑 |
| 性格 | 表面憨厚、内心阴鸷、对"信"和"义"有扭曲的执念 |
| 武功 | 高(北疆历练) |
| 嗜好 | 练刀、看边塞诗、养鹰 |
| 弱点 | 母亲(燕国公主)的影响太大;对"被信任"有过度的渴望 |

### 三重身份
- **表面身份**:晋阳王世子,新帝党的"潜在盟友"
- **真实动机**:**让晋阳萧氏在推恩令下活下来,必要时——反抗**。他不反大衍,但他反"被吞并"
- **暗面**:他想跟沈彦做"真朋友",但他更想要晋阳萧氏的存续。如果两者冲突,他选后者

### "母妃是燕国公主"——展开

- 萧璎母妃是燕国公主(二十年前政治联姻),已故
- 萧璎体内有燕国皇室血脉
- 这条线**被朝廷视为"通敌隐患"**
- 第二幕后段:沈彦发现萧璎身边有"燕国口音的人"——这是"通敌"的实证
- 第三幕:萧璎被指控"通敌燕国"——**有真有假**
  - 假:他没跟燕国勾结
  - 真:他跟燕国**有联系**——但只是"母亲娘家",不是叛国
- 沈彦**匿名**告知萧璎"小心被构陷通敌"——但他无法完全洗清萧璎
- 萧璎的最终选择:**自我流放到燕国**(不是叛逃,是"退出")——跟沈彦归隐是**同一种选择**的另一种形态

### 弧光
- **起**:沈彦的阳谋,对我有利。我愿意跟他合作。
- **承**:我越来越信任他。但我也越来越觉得——他可能随时抛弃我。
- **转**:裴正则离间我们。我开始怀疑沈彦。
- **合**:沈彦归隐。我没有怪他。我只是知道——北疆,终究要靠我自己。我选择离开大衍,去燕国——**不是叛逃,是不玩了**。

### 与主角的关系
- **政治盟友 + 情感上的"想要但得不到的友情"**。萧璎对沈彦有一种"我想成为他"的羡慕,但也有"他随时会背叛我"的恐惧
- **功能**:为第三幕的"通敌案"提供真伪混杂的复杂性;为第四幕"归隐"提供"另一种退出"的对照

## 六、叶孤鸿(青衫盟大侠·理想主义的破灭)

| 维度 | 内容 |
|------|------|
| 年龄 | 34 岁(开篇) |
| 出身 | 寒门,师从青衫盟老盟主,十五岁出道 |
| 表面身份 | 青衫盟现任盟主,天下第一游侠 |
| 真实处境 | 他真心相信"侠之大者,为国为民",但他**知道**青衫盟被新帝党渗透——**他选择不揭穿**,因为渗透的人做的事"是好事"(帮他扶助寒门) |
| 性格 | 豁达、磊落、有真性情、有时天真 |
| 武功 | 极高(江湖前三) |
| 嗜好 | 喝酒、写诗、看人打抱不平 |
| 弱点 | 理想主义的"明知被利用但选择不反抗"——这是另一种"被驯化" |

### 三重身份
- **表面身份**:大侠,士林的精神领袖之一
- **真实动机**:**让天下寒门子弟有路可走**。他支持科举、支持推恩令、支持一切"让寒门出头"的政策
- **暗面**:**他知道被渗透,但选择不揭穿**——这是"理想主义的破灭":你以为你坚守的东西,其实一直在被利用,而且**利用它的人做的事,跟你一样**——你没法反对

### 弧光
- **起**:沈彦是寒门之光。我要保他。
- **承**:我帮沈彦,发现他越来越像"朝堂的人"。我开始失落——但我还是帮他。
- **转**:我越来越清楚地知道,自己被利用。但我能怎么办?揭穿?揭穿就是"否定自己帮过的所有寒门子弟"
- **合**:沈彦归隐。我重新定义"侠"——**不是救天下,是救自己**。但我没有沈彦的勇气——我还在江湖里耗着,直到老死

### 与主角的关系
- **精神上的"对照"**。沈彦是"用阳谋救自己",叶孤鸿是"用武功救别人"。两条路都到不了终点
- **觉醒的"对称"**:沈彦意识到"阳谋被收编",叶孤鸿意识到"侠义被收编"——但两人选择不同:沈彦退出,叶孤鸿留下耗着
- **功能**:为主角提供"另一种活法"的镜像;为第三幕的"信任危机"提供另一种声音

## 八、关系网(简化)

```
                 仁宗(沈承熙)
                  │
        ┌─────────┼─────────┐
        │         │         │
    裴正则    崔玄礼     萧璎(晋阳王世子,母妃是燕国公主)
   (新帝党)  (清河崔氏)    (藩王+第四变量)
        │         │         │
        │         │     ┌───┴───┐
        │         │   苏蘅   叶孤鸿
        │         │  (听雨楼)(青衫盟)
        │         │     │
        └────┬────┘     │
             │          │
           沈彦 ←───────┘
           (主角,破落皇族)
             │
           沈安(老仆)
```

> **注意**:**所有"主要对手",都是"镜像"**。每个对手都代表主角"可能成为的另一个人"。
> - 崔玄礼 = 用了阳谋却输了的人
> - 裴正则 = 维护阳谋体系的人
> - 萧璎 = 用阳谋求自保的人(最终选择"退出"到燕国)
> - 苏蘅 = 不能选归隐的人(把归隐的可能寄托在沈彦身上)
> - 叶孤鸿 = 想救天下但救不了的人(知道被利用但选择不反抗)
>
> 这种"镜像结构",是权谋文避免工具人的关键。
