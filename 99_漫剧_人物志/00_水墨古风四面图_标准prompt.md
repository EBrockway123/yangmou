# 《阳谋》人物志 · 水墨古风四面图 · 标准 Prompt 流程

> **风格**：水墨古风（非写实、非 Q 版、非卡通）
> **画幅**：9:16 竖屏
> **流程**：① 正面 → ② 审查 → ③ 正面作参考 → ④ 生成后/左/右
> **要求**：每个角色 4 张图，AI 用同一参考图保持一致性

---

## 零、通用水墨古风基础 prompt（每个角色都要加）

```
传统中国水墨画风格，工笔淡彩。
墨色为主，辅以淡赭、淡青、淡朱砂。
线条流畅有书法笔意，衣纹用"兰叶描"或"铁线描"。
人物面部用"三白法"（额、鼻、下巴留白），
其余用淡墨层层晕染。
背景纯白（不打底色）。
画幅 9:16 竖屏，人物居中，全身可见。
```

## 四、风格统一核心要点

1. **同一角色 4 视图必须是同一张脸** — 用参考图机制（`input_file_paths`）
2. **水墨古风 4 大特征**：
   - 墨色为主，辅以淡赭/淡青/淡朱砂
   - "三白法"（额、鼻、下巴留白）
   - 衣纹用"兰叶描"或"铁线描"
   - 背景纯白不打底色
3. **禁用词**：不要 "Q 版"、"卡通"、"写实摄影"、"3D"、"插画"、日韩动漫风
4. **时代锁定**：宋代架空，承和年间
5. **服饰锁定**：交领右衽直裰（不可错领）
