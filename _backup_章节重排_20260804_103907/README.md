## 🌟 核心母题

> **在别人画好的棋盘上,你成了最会下棋的棋子。**

阳谋的最高一层:不是让对手"明知是坑还得跳",而是让对手**自己相信"只有阳谋这一条路"**。
这才是真正的牢笼。

**沈彦的觉醒不是"看破",是"退出"**——自由不是赢,是退出。

## ✍️ 写作流程(简版)

1. **开写前**:读 04 + 09 各 1 遍,准备灵感本
2. **第一稿**(8-10 个月):每天 2000-3000 字,每天 1-2 章
3. **修改**(3-4 个月):6 轮修改(结构/文笔/AI 味/通读/反馈/定稿)
4. **定稿**(1 个月):目录 + 前言 + 后记 + 校对

> 完整流程见 `01_大纲与节奏\05_写作流程_AI味自查_破落皇族伏笔.md`

## 💡 几条核心原则(贯穿全书)

1. **每个阳谋都有代价**——没有"白赢"
2. **每个对手都有逻辑**——不"降智"
3. **沈彦始终"克制"**——情感用"小动作"代替
4. **破落皇族伏笔"缓缓漏出"**——不"大揭秘"
5. **感情是"克制中的微光"**——不是"狗血"
